# 2026-09-28 联网、工具、注册与 EMOS 接入

## 问题与修复

- 五个 Agent 普通聊天原先只有模型回复。现在明确联网要求会执行 `web.search` 或 `web.read`，再将实际来源交给模型；聊天持续保留，来源可点击。默认自动判断，也可关闭联网或明确本轮联网。
- 公开检索使用 Bing RSS，故障时尝试 Google News RSS；只发送本轮公开关键词，不发送历史、记忆或凭据。检索摘要不冒充网页正文。公开网页读取限制 HTTPS、公网 DNS、响应大小、跳转与超时，取消会终止请求。
- 选择已启用的 Skill/Agent 工具后，在同一对话执行保存版本、参数和组合工作流，并记录真实用量；Mini App 回到隔离工具页面。本人资料检索走权限过滤后的本地工具。
- 注册入口明确区分登录与注册，密码 8—128 位、二次确认、错误保留，账号去除首尾空白、称呼长度受限；成功创建服务端账号和会话，刷新可恢复。
- 合入上游服务 PR #4。EMOS 原生 API 与应用同步协议不同，补了仅监听本机、带服务端令牌的受限适配器，使用 EMOS 原生 SQLite 存储。固定数据库路径，保留 owner、分配、阶段、来源、修订、幂等及遗忘回执；撤回最后一条后旧写入也不能恢复内容。

## 边界

公开检索与公开网页只读已实现。需要登录、验证码或反爬的网页不保证可读；不伪造结果。邮件发送、登录后网页代操作、支付、部署平台等尚未选择的外部服务不因此自动接通。EMOS 原生自动抽取/反思/召回未启用，当前仍由应用执行已经确认的学习与分配规则，适配器同步受限记录。Skill Foundry 与 PA 网关只是合入源码，没有参与本应用执行；健康检查只说明可达。
