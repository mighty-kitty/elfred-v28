# 自动学习与分配规则验收

依据：五个子 Agent 详细原稿 §3.5、§3.6、§5，页面确认台账 M10，找回的初始化八题原稿及后续确认。整编文档仅作导航；未重新核对飞书版本。

| 原稿要求 | 代码实现 | 测试与实际交互 |
| --- | --- | --- |
| 低风险可撤销工作偏好无需逐条确认 | 本人完整原句限定风险、领域与场景；明确工作偏好自动记录，模型解释只能在原句范围内生成待验证理解 | 私聊说“以后写产品方案先给结论”，无需点击确认即在后续产品方案中调用 |
| 高影响内容需确认；临时状态不形成画像 | 健康、身份、财务、价值观等和未识别持久个人描述待核对；临时情绪、单次喜好、引文、密钥不写入 | 健康、在读身份、价值判断、未知片剂与“我现在很难过”反例 |
| Person／领域／专业／任务分层，而非全库共享 | 通用偏好只保存一份；Person 按用途提供最少字段。领域私有，工具经验限定同一领域、工具版本；任务授权不能转为长期画像 | 创作聊天表达提醒习惯归执行；通用中文偏好可分配，限定报告偏好不扩到五系统；其他账号、群聊及共享项目隔离 |
| 理解四阶段按证据自动判断 | 明确表达→真实应用自然反馈→不同日期、不同实际场景持续支持；有效反证阻止稳定。全局理解的应用证据按使用领域独立判断 | 实际任务验收反馈、连续表扬、否定及混合反馈、反馈回复、跨领域证据反例；不按聊天量或任务数量涨级 |
| 指正与遗忘影响后续使用 | 相同领域、话题、场景内替代；来源版本、撤权、隐藏、到期与删除检查正反证及派生记录。失去证据的推断仍为推断 | 修改产品方案不删除周报偏好；删反馈使对应证据失效；删理解后停止召回；旧账号迁移不复活被删记录 |
| 首页及记忆库显示真实理解 | 首页各领域分别呈现实际阶段；记忆库显示自动记录、已确认和待核对，支持修改、撤销 | 手机 390×844 与桌面 1365×900 实际点击和截图 |
| 统一记忆中枢接口留好 | 本地授权缓存可用；持久队列和预留适配协议携带分配限制、类型、来源、阶段与删除回执 | 适配器测试；外部 EmoS 尚未配置，不声称已联通 |

主要实现：`memory-learning.mjs`、`memory-allocation.mjs`、`memory-feedback.mjs`、`memory-validity.mjs`、`knowledge.mjs`、`runtime.mjs`、`onboarding-choice.mjs`，以及首页理解、私聊、记忆库显示。

验证：后端 230/230，产品 35/35，生产构建通过；真实模型三次请求、1844 tokens，验证自动记录、无需确认召回、自然反馈形成证据及隐藏结构化包装。另有隔离浏览器验收，无生产数据或真人社区测试内容。代码审查发现的误分配、误替代、误升级和证据失效问题已补回归。

边界：目前由本地服务执行这套受限学习与分配规则，未宣称 Jev 或外部 EmoS 真实接通。方法经验不是自动改写 Skill 工作流；缺失的独立反馈进化后端仍在会议差距台账中。本轮尚未更新旧公网服务器，部署仍缺可用服务器认证。
