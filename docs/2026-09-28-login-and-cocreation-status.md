# 登录与共创当前状态（2026-09-28）

## 已可使用

- Elfred 账号支持邮箱地址、手机号或用户名加密码注册／登录。邮箱地址中的 `+` 别名也可用。该路径只验证密码，**没有验证邮箱或手机号的所有权**；不能将其标成“邮箱验证码登录”或“短信登录”。
- 五个 Agent 的初始化有逐个与同一会话群聊两种编排，询问具体兴趣领域；选择进入探索 Agent 初始理解与公开资讯筛选。群聊的补充输入会调用当前问题对应的 Agent，只有用户明确选择和确认的内容进入初始化记忆。
- 首页显示五个 Agent 的对齐阶段。私人 Agent 朋友圈中可邀请另一 Agent 对同一事件提出评论；模型回复需要本人验收才进入讨论。
- 社区共创：真人发帖 → 认领或申请 → 各自授权本人 Agent → 工作副本 → 项目内讨论、阶段成果和依赖 → 本人提交 → 发起者审核 → 真人发布版本。社区公开内容始终由真人确认。

## 不能标为“已接通”的登录

| 方式 | 应用所有者需取得 | 工程接入前提 |
| --- | --- | --- |
| 微信网站登录 | 在[微信开放平台](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html)注册并审核网站应用，取得 AppID、AppSecret、授权回调域名 | 服务器校验 OAuth 回调、state、唯一用户标识与账户绑定；应使用 HTTPS 正式域名 |
| Apple ID 网站登录 | [Apple Developer 配置](https://developer.apple.com/help/account/capabilities/configure-sign-in-with-apple-for-the-web/)中主 App ID、Services ID、Team ID、签名私钥、已登记的域名与返回地址 | 服务器验证身份令牌、state、密钥轮换及账户绑定；需要正式域名和 HTTPS |
| 短信验证码 | 选择短信服务商并完成[签名／模板审核](https://cloud.tencent.com/document/product/382/43070)，提供应用密钥、签名和模板 ID | 服务端生成短时一次性验证码、限流、发送、核销与错误处理；不能把模型 API Key 当短信密钥 |
| 邮箱验证码 | 选择邮件服务商并验证发信域名，例如[域名验证流程](https://resend.com/docs/add-a-domain)，提供受限发信密钥 | 同样需要短时一次性验证码、限流、核销与发送失败处理 |

当前用户确认这四项平台配置都没有。项目不模拟成功认证，也不自动给陌生邮箱或手机号建立已验证身份。凭据应写入服务器私有环境配置，不提交 GitHub。

## 与 Tutti 的关系

设计原稿与调研明确：Tutti 的核心是多人和各自 Agent 在 Room 共享讨论、执行状态与成果；没有证据表明 Tutti 的官方流程包含 Elfred 的公开“共创帖 → 认领／申请 → 双层审核”。Elfred 借鉴持续项目空间与工作状态，但保留真人发布、隔离副本、权限和贡献审核。当前代码有持久项目、成员反馈、阶段结果、依赖、工作副本、贡献审核、版本发布；**没有 Tutti VM 那种实时共享工作环境、同文件并发或借用他人 Agent**，不能说两者完整相同。
