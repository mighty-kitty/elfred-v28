# 第二、四页合并说明

当前版本包含 PR #1 和 PR #2。数据源统一为 V28 登录会话、SQLite 对象和命令服务；仓库未提交 `elfred-page2-api`，不依赖其独立端口。

## 已接通

- 工具、记忆、文档、成果、关系和个人资料读取同一会话。新账号显示空态，切换账号清除上一账号投影。
- 文件、网址、工具固化、任务创建和 Agent 持久对话沿用现有命令服务。
- 编辑资料逐字段保存；一次操作等待一次 `profile.save` 完成，失败保留编辑内容。空昵称保存为“路人”。
- 头像、封面和等级显示偏好保存并在刷新后恢复。媒体写入不覆盖其他资料字段。
- 第四页 Agent 动态显示朋友圈最近三条，排除隐藏和非活动记录；完整列表入口返回首页朋友圈。
- 设置保留现有权限、数据导出、调用配额与供应商对账。服务状态以当前快照为准。
- 轻量测试与能力估计在本仓库内：题库、计分、起点与五维估计共用 `app/v28/core/dimensions.mjs`，
  作答由命令 `questionnaire.submit` 写进当前会话的对象表（`dimension_baseline`），
  `GET /api/elfred/page2/questionnaire` 给题面。每维的数字来自**测试起点 + 每条被本人验收的成果自己的表现**
  （不是这张卡的分）：验收时填的满意度决定这条成果的表现分，权重按"本人验收"一档，旧证据按 30 天半衰期衰减；
  没测过、成果又不够 3 条的维不给数字，界面走空态。
